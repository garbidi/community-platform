# Community Platform

Рабочая платформа бизнес-сообщества, которое проводит мастермайнды для
предпринимателей: потоки по 100+ участников, команды, менторы, организаторы.
Платформа собирает в одном месте то, что раньше жило в десятке Google-таблиц,
телеграм-чатах и в головах координаторов, и снимает с людей ручную работу:
данные приходят из чатов, записей созвонов, форм оплаты и таблиц сами, а AI
разбирает их и раскладывает по местам.

> Обезличенная витринная версия проекта, разработанного для реального клиента.
> Название сообщества, имена, логины, идентификаторы чатов, адреса и фирменный
> стиль заменены. Данных участников в репозитории нет.

## Что делает

- **Роли и доступ на уровне данных.** Участник, расширенный тариф, ментор,
  координатор, администратор. Роль ограничивает выборку, а не видимость кнопок:
  ментор получает из базы только своих участников. Каждое открытие чужого
  профиля и каждый поиск пишутся в журнал доступа.
- **Потоки и команды.** Создание потока, команды из Google-таблиц с проверкой
  структуры, закрепление менторов, таблица потока с переносом участников между
  потоками, лидерборд вовлечений и доска «кто идёт дальше».
- **Разборы по записям созвонов.** Ментор загружает запись — звук расшифровывается
  (GigaAM / faster-whisper), Claude пишет выжимку для ментора и вынимает из неё
  цели участника, шаги и сроки. Участник ничего не заполняет: декларация
  собирается из разговора, ментор только подтверждает.
- **Поиск и аналитика по переписке.** Корпус из 28 тыс. сообщений и 2,7 тыс.
  расшифрованных голосовых, FTS5-поиск с подсветкой, 18 поведенческих метрик
  на участника, статусы «активен / притих / выпал».
- **Финансы из чата.** Claude дважды в день разбирает сообщения финансового чата
  в операции (приход, расход, проект, статья, кошелёк). Что непонятно — не
  угадывает, а задаёт вопрос с вариантами; ответ человека становится примером
  для следующих разборов. Отсюда ДДС по статьям и остатки по кошелькам.
- **Автоматические новости об оплатах.** Оплата в форме на сайте → пост в чат
  сообщества с текстом от Claude и фото участника → аватар чата обновляется
  счётчиком «вовлекли N». Всё, что уходит в Telegram, проходит через «замок
  отправки»: выключено / только тестовые чаты / везде.
- **Зал мероприятия.** Страница со 110 креслами, в каждом — фото оплатившего
  участника; данные перечитываются из таблицы организаторов в фоне.
- **AI-помощник в Telegram для организаторов.** Отвечает на вопросы словами
  («кто затих на этой неделе», «почему у участника 0 вовлечений»): три движка —
  Claude Code с инструментами по данным, Claude API с tool use, разбор
  правилами как запасной. Понимает голосовые и отвечает голосом (Silero TTS +
  RUAccent для ударений).
- **Мастер развёртывания.** Владелец сам вводит токен бота, входит в Telegram
  и Claude прямо со страницы настройки — без доступа к серверу.

## Стек

Python 3.12 · FastAPI · Jinja2 · SQLite (FTS5) · Telethon · Claude API и
Claude Code CLI · faster-whisper / GigaAM · Silero TTS · Google Sheets API ·
Docker Compose · Caddy

Около 17 тыс. строк Python, 43 шаблона, 270+ маршрутов.

## Архитектура

```
app/
  main.py           FastAPI: маршруты, сессии, роли
  access.py         права и журнал доступа
  flows.py          потоки, команды, менторы; синхронизация с таблицами
  roster.py         состав потока из Google-таблиц команд
  rows.py           таблица потока: оплата → строка, перенос между потоками
  reviews.py        разборы по записям: STT → выжимка Claude → цели
  decl.py           декларации участников из разборов
  finance.py        финансовый чат → операции, ДДС, кошельки
  sensation.py      оплаты из формы → посты в Telegram
  hall.py           зал мероприятия по таблице организаторов
  tg_account.py     аккаунт сообщества в Telegram, замок отправки
  assistant.py      инструменты помощника по данным
  brain.py          движки помощника: Claude Code / Claude API / правила
  calls.py          созвоны из бота записи, опознание участников по подписям в Зуме
  templates/        Jinja2, один набор токенов оформления (static/tokens.css)
bot.py              Telegram-бот помощника
voice/              распознавание и синтез речи
deploy/             Docker-образ мастера развёртывания, Caddy с автоматическим TLS
platform/           docker-compose основной платформы
```

Решения, которые стоит отметить:

- **SQLite в режиме WAL и одна транзакция на синхронизацию.** Поштучная запись
  держала базу ~10 секунд и роняла запросы с `database is locked`; запись
  пачкой в `BEGIN IMMEDIATE` сняла проблему без смены СУБД.
- **Claude не угадывает.** В финансах и в опознании участников неуверенный
  результат превращается в вопрос человеку, а ответ — в пример для модели.
- **Защита помощника от prompt injection и необратимых действий** — три слоя:
  правила в системном промпте, запреты в настройках инструментов, ежедневная
  копия баз только для чтения. Проверено вложенными в файлы «командами».
- **Тяжёлые модели вне бота.** Распознавание, синтез и упаковка в ogg/opus
  живут в разных окружениях; синтез — постоянный процесс, чтобы не грузить
  модели 14 секунд на каждую фразу.

Подробности по каждому разделу — в [docs/INTERNALS.md](docs/INTERNALS.md),
правила оформления — в [docs/DESIGN.md](docs/DESIGN.md).

## Запуск

```bash
pip install -r requirements.txt
python3 seed.py --password <пароль>   # база приложения и учётки по ролям
./serve.sh start                      # http://127.0.0.1:8000
```

Для продакшена — `platform/docker-compose.yml`, переменные окружения описаны
в `deploy/env.example` и `bot.env.example`.

# Design — панель сообщества «Вершина»

Зафиксированная дизайн-система приложения. Каждая страница читает этот файл
перед вёрсткой. Не переизобретать на страницу — расширять или править здесь.

Источник ДНК: сайт заказчика vershina-community.ru (бренд «Вершина», для него же
и делается панель). Взяты палитра, дисплейный характер, мотив фигурных скобок
и логотип. Пиксели и вёрстка сайта не копировались.

## Genre
modern-minimal — внутренняя рабочая панель с плотными данными.

## Macrostructure family
- Приложение (обзор, участники, карточка, поиск, поток, доступы, журнал):
  **Workbench** — фиксированный навигационный рельс слева, компактная шапка
  страницы, дальше данные без маркетинговой обёртки. Варьируется только
  содержимое шапки и состав таблиц.
- Контент (расшифровка созвона): **Long Document** — одна колонка, мера 68ch.
- Вход: **Manifesto** — тёмно-синий плакат на весь экран, логотип, одна форма.

Отход от каталога скилла: N1a–N13 описывают навигацию лендингов; у приложения
8 разделов с доступом по роли, поэтому N3 (side-rail) расширен до полноценного
app-рельса с подписями. Зафиксировано осознанно.

## Theme
- `--color-paper`      oklch(96.4% 0.018 89)   кремовый фон бренда
- `--color-paper-2`    oklch(93.4% 0.024 88)   углубление, наведение
- `--color-panel`      oklch(98.8% 0.010 89)   поверхность данных
- `--color-rule`       oklch(87.0% 0.020 86)   волосяная линия
- `--color-neutral`    oklch(58.0% 0.030 276)  второстепенный текст
- `--color-muted`      oklch(45.0% 0.045 276)  подписи
- `--color-ink`        oklch(23.0% 0.088 275)  брендовый тёмно-синий вместо чёрного
- `--color-navy`       oklch(34.1% 0.115 276)  рельс, плашки
- `--color-navy-deep`  oklch(19.0% 0.075 275)  плакат входа
- `--color-accent`     oklch(63.3% 0.200 37)   брендовый оранжевый
- `--color-accent-ink` oklch(98.8% 0.010 89)   текст на оранжевом
- `--color-focus`      oklch(63.3% 0.200 37)
- `--color-warn`       oklch(70.0% 0.130 70)   «притих»

Акцент — маркер, не плашка: активный пункт рельса, скобки в заголовке, фокус,
подчёркивание ссылки при наведении, один статус. Не больше 3% площади экрана.
Тёмная тема: бумагой становится тёмно-синий, якорный тон 275° не меняется.

## Typography
- Display: Unbounded 600, tracking −0.03em, роман (никогда не курсив);
  в рельсе — Unbounded 400, 12px, tracking +0.01em
- Body: Onest 400 / 500 / 600
- Мера текста: 68ch, для расшифровок 72ch
- Шкала: 1.25 (мажорная терция), якорь `--text-display` = clamp(1.75rem, 1.2rem + 1.6vw, 2.6rem)
- Числа в таблицах и плитках: `font-variant-numeric: tabular-nums`
- Моно-шрифта нет: подписи моно — известный признак сгенерированного интерфейса

## Spacing
Шкала 4pt с именами `--space-3xs … --space-3xl`, значения в `app/static/tokens.css`.
Страницы используют только имена, не сырые значения.

## Motion
- Переходы только по `transform` и `opacity`, 140–220 мс, `--ease-out`
- Реакция на действие человека: наведение, фокус, нажатие. Появлений по скроллу нет
- `prefers-reduced-motion: reduce` — остаётся только смена цвета

## Microinteractions stance
- Тихое подтверждение: страница просто показывает новое состояние
- Фокус видно всегда, обводка появляется мгновенно, без анимации
- Наведение никогда не единственный способ узнать информацию

## CTA voice
- Основное действие: заливка тёмно-синим, радиус 6px, текст глаголом
  («Войти», «Показать», «Сохранить закрепления»)
- Второстепенное: обводка волосяной линией, прозрачный фон
- Оранжевая заливка не используется ни для одной кнопки

## Per-page allowances
- Страницы приложения: без иллюстраций и картинок — данные несут страницу
- Страница участника: только его активность, без архива переписки и речевых метрик
- Вход: логотип бренда как единственный графический элемент
- Расшифровки: только типографика

## What pages MUST share
- Логотип и рельс
- Тёмно-синий как цвет текста, оранжевый только как маркер
- Unbounded + Onest
- Шапка страницы: `{Заголовок}` в скобках + одна строка происхождения данных
- Голос кнопок и волосяные линии таблиц

## What pages MAY differ on
- Состав шапки и набор плиток
- Плотность таблиц
- Long Document вместо Workbench для расшифровок

## Provenance
ДНК снята с публичного сайта заказчика по его же заказу: панель делается для
сообщества «Вершина», логотип взят с их сайта с ведома заказчика.

## Exports
Токены живут в `app/static/tokens.css` (файл отдаётся сервером, поэтому лежит
в static, а не в корне) и подключаются первым `@import` в `app/static/style.css`.
